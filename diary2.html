🚀 Flex布局让我彻底放弃表格

📅 2026年7月25日 · 阅读约 4 分钟

每个前端初学者都有一段用 <table> 硬怼布局的黑历史，我也不例外。 直到某个深夜，我对着一个死活调不对齐的导航栏崩溃了。

😭 表格布局的噩梦

最开始做导航栏，我是这样写的：

<table width="100%"> <tr> <td align="center">首页</td> <td align="center">关于</td> <td align="center">服务</td> <td align="center">联系</td> </tr> </table>

每次加一个新菜单项，就得回去数 colspan 对不对。改一次样式，整个表格就歪了。 更别提想做 响应式 —— 表格在手机上简直是灾难。

💡 遇见 Flex 的那天

直到有一天，我在 B 站刷到了 Flex 布局的教学视频。看完我只想说一句话：

🤯 "原来布局可以这么简单？那我以前在表格里受的苦算什么？"

同样的导航栏，用 Flex 只需要这几行：

<nav class="nav"> <a href="#">首页</a> <a href="#">关于</a> <a href="#">服务</a> <a href="#">联系</a> </nav>
/* 就这几行，搞定一切 */ .nav { display: flex; justify-content: center; gap: 30px; }
✅ 一行 display:flex 胜过 10 行 table 代码。

📊 对比一下就知道差距

❌ 表格布局（以前的我）

代码臃肿
响应式基本靠玄学
改一次崩一次
垂直居中要 valign

✅ Flex 布局（现在的我）

代码精简
天然响应式支持
justify-content 一键居中
align-items 垂直居中

🎯 给我的启发

这次经历让我明白了一个道理：选对工具比盲目努力更重要。 如果我一直抱着表格不放手，可能到现在还做不出一个像样的导航栏。

现在我的原则是：布局首选 Flex，二维布局上 Grid，不到万不得已不用 float，永远不用 table 做布局。
